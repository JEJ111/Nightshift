NightShift

NVIDIA frame generation and DLAA for Nivalis Nights.

Install in five steps

  1. Save and close Nivalis Nights.
  2. Save the downloaded ZIP.
  3. Extract it first. In File Explorer, right-click the ZIP, choose Extract All, and click Extract. Open the extracted NightShift-0.5.2 folder.
  4. Open Install NightShift.exe, the application with the NightShift icon. Keep the payload and Tools folders beside it. If setup reports access denied, right-click the application and choose Run as administrator.
  5. Launch through Steam and load your save. Press F11 to select frame generation, F5 to toggle DLAA, and F7 to hide or show the menu.

If the installer says the package isn't fully extracted, close it and use Extract All on the ZIP. Opening the ZIP alone doesn't extract all its files.

Updating from 0.5.0 or 0.5.1

Save and close the game, extract 0.5.2 into a new folder and run its installer over the existing installation. No uninstall is needed. Your settings, saves, captures and caches are preserved.

Remove or recover

Close the game, open Tools, and run Uninstall NightShift.cmd. The optional Restore Working DLSS.cmd restores the matching 0.5.2 DLAA-only build.
